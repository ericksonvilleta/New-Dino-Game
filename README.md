# 🦖 Custom Web Dinosaur Runner Game

Welcome to the official repository for a fully customized, feature-rich web dinosaur runner mini-game inspired by the classic offline Chrome Dino experience. Developed by **Erick Villeta**, this project transforms a simple browser pastime into an engaging, multi-environment visual adventure designed for seamless integration into modern web pages.

## ✨ Core Features

**Dynamic Environment Transitions:** Experience a living world as the background smoothly shifts through four distinct atmospheric settings—dawn, day, sunset, and night—evolving automatically as your score climbs higher.

**Progressive Difficulty Scaling:** The game dynamically adjusts obstacle speeds and introduces increasingly complex cactus variations and unique flying rock hazards at specific score milestones to thoroughly test your reflexes.

**Immersive Web Audio FX:** Say goodbye to external media dependencies. The game utilizes the native Web Audio API to generate custom, crisp audio feedback for jumping, cactus impacts, and rock collisions entirely in real-time.

**Persistent High Score Tracking:** Built-in local storage support ensures your personal best record is safely remembered across sessions, keeping the competitive spirit alive every time you play.

## 🕹️ How to Play

Getting started is quick and intuitive. Simply press the **Space bar** on your keyboard or tap directly on the game container to jump over incoming obstacles and start your run. If you crash, hitting Space or tapping again will instantly restart the challenge so you can beat your previous high score.

## 🛠️ Built With

This project is crafted using lightweight, high-performance web standards including vanilla JavaScript for game loops and physics, CSS3 for smooth animations and transitions, and HTML5 markup. It requires no external frameworks or libraries, making it lightning-fast to load and easy to embed anywhere.
